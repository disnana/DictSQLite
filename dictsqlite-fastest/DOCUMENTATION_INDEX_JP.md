## 🚀 クイックスタートガイド

### 1分で始める
```bash
pip install apsw
```
```python
from dictsqlite_fastest import DictSQLiteFastest as DictSQLite
with DictSQLite('my_db.db') as db:
    db['hello'] = 'world'
    print(db['hello'])  # 'world'
```

### 5分で最適化
```python
with DictSQLiteFastest(
    'optimized.db',
    journal_mode='WAL',
    cache_size=10000
) as db:
    db.warmup_connection()
    # 高速化された操作を実行
```
