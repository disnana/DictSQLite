## 🔧 技術的詳細

### APSW最適化設定
```python
# 主要PRAGMA設定
synchronous=NORMAL          # 安全性と速度のバランス
cache_size=-64000          # 64MBキャッシュ
temp_store=MEMORY          # メモリ内一時テーブル
mmap_size=268435456        # 256MMメモリマップド I/O
page_size=65536            # 大きなページサイズ
auto_vacuum=INCREMENTAL    # インクリメンタルバキューム
```

### パフォーマンス統計
```python
db = DictSQLiteFastest('db.db')
stats = db.get_performance_stats()
print(stats)
# {'database': 'db.db', 'table': 'main', 'journal_mode': 'WAL', ...}
```

### 圧縮機能の使用
```python
# 圧縮を有効化（1KB以上の値を圧縮）
db = DictSQLiteFastest('db.db', 
                       enable_compression=True, 
                       compression_threshold=1024)
```
