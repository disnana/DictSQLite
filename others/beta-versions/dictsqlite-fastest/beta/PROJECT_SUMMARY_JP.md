## 実装した最適化アルゴリズム

### 1. LRUキャッシュ（Least Recently Used）
**目的**: 頻繁にアクセスされるデータをメモリに保持

**実装詳細**:
- `collections.OrderedDict` を使用
- スレッドセーフ（`threading.Lock`）
- O(1)アクセス時間
- デフォルト容量: 10,000アイテム

**効果**: 
- キャッシュヒット時のディスク読み込みをゼロ化
- **21.03倍の高速化**

**コード例**:
```python
class LRUCache:
    def get(self, key):
        if key in self.cache:
            self.cache.move_to_end(key)  # LRU順序更新
            return self.cache[key]
        return None
    
    def put(self, key, value):
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)  # 最古を削除
```

### 2. 書き込みバッファリング（Write-Behind Caching）
**目的**: 小さな書き込みをメモリに蓄積し、一括でディスクに書き込む

**実装詳細**:
- メモリバッファに書き込みを蓄積
- 閾値（デフォルト1,000件）または時間（デフォルト5秒）でフラッシュ
- 削除操作もバッファリング

**効果**:
- ディスク書き込み回数を削減
- **6.26倍の高速化**

**アルゴリズム**:
```python
class WriteBuffer:
    def add(self, key, value):
        self.buffer[key] = value
        if self._should_flush():
            return True  # フラッシュ必要
        return False
    
    def _should_flush(self):
        # サイズまたは時間で判断
        return (len(self.buffer) >= self.threshold or
                time.time() - self.last_flush >= self.interval)
```

### 3. 先読みキャッシング（Read-Ahead Prefetching）
**目的**: アクセスパターンに基づいて関連データを事前にキャッシュ

**実装詳細**:
- `prefetch_keys()` メソッドでキーリストを指定
- バルク読み込みAPIを活用
- キャッシュに一括追加

**効果**:
- 次のアクセスでキャッシュヒット率向上
- **バルク読み込み7.74倍高速化**

**使用例**:
```python
# アクセスパターンが予測できる場合
related_keys = ['user_1', 'user_2', 'user_3']
db.prefetch_keys(related_keys)
# これらのキーへのアクセスは超高速に
```

### 4. アグレッシブメモリPRAGMA設定
**目的**: SQLiteレベルでメモリ使用を最大化

**設定内容**:
```python
PRAGMA cache_size = -256000      # 256MB SQLiteキャッシュ
PRAGMA mmap_size = 1073741824    # 1GB メモリマップ
PRAGMA journal_mode = WAL        # Write-Ahead Logging
PRAGMA temp_store = MEMORY       # 一時データをメモリに
PRAGMA locking_mode = EXCLUSIVE  # 排他ロック（高速化）
```

**効果**:
- SQLiteのディスクI/Oを削減
- 全体的なパフォーマンス向上

### 5. メモリオンリーモード
**目的**: 完全にメモリ内で動作し、最高速度を実現

**実装**:
```python
db = DictSQLiteFastestBeta(':memory:', memory_only=True)
```

**効果**:
- ディスクI/Oがゼロ
- 一時的なデータ処理に最適

## ディスクアクセス削減の仕組み

### 読み込み時のフロー
```
1. キーへのアクセス要求
   ↓
2. LRUキャッシュをチェック
   ↓
   ├─ ヒット → メモリから即座に返す（21倍高速）
   │
   └─ ミス → 3. 書き込みバッファをチェック
              ↓
              ├─ 存在 → バッファから返す
              │
              └─ なし → 4. ディスクから読み込み
                         ↓
                         5. キャッシュに追加
                         ↓
                         6. 値を返す
```

### 書き込み時のフロー
```
1. 書き込み要求
   ↓
2. LRUキャッシュを更新
   ↓
3. 書き込みバッファに追加
   ↓
4. 閾値チェック
   ↓
   ├─ 閾値未満 → メモリに保持（即座に完了、6倍高速）
   │
   └─ 閾値達成 → 5. バッファフラッシュ
                   ↓
                   6. ディスクに一括書き込み
                   ↓
                   7. バッファクリア
```

## 使用方法

### インストール
追加のインストールは不要です。

### 基本的な使用
```python
from dictsqlite_fastest.beta import DictSQLiteFastestBeta

# コンテキストマネージャ使用（推奨）
with DictSQLiteFastestBeta('data.db', cache_capacity=10000) as db:
    db['key1'] = 'value1'
    print(db['key1'])
    
    # 統計情報
    stats = db.get_beta_stats()
    print(f"ヒット率: {stats['cache']['hit_rate']:.2f}%")
```

### 設定のカスタマイズ

**読み込み中心**:
```python
db = DictSQLiteFastestBeta(
    'read_heavy.db',
    cache_capacity=100000,   # 大きなキャッシュ
    write_buffer_size=100    # 小さなバッファ
)
```

**書き込み中心**:
```python
db = DictSQLiteFastestBeta(
    'write_heavy.db',
    cache_capacity=5000,      # 適度なキャッシュ
    write_buffer_size=10000   # 大きなバッファ
)
```

**メモリオンリー**:
