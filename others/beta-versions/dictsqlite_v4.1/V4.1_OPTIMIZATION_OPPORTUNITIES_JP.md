## 🎯 主要な最適化機会

### 1. 非同期I/O処理（最優先）

**現状の問題点**:
- `AsyncDictSQLite::set_async()`が各呼び出しごとにMutexロックとストレージ書き込みを実行
- バッファリング機構が未実装
- Beta版Python実装では1000件の書き込みに**30秒**かかることを確認済み

**最適化の余地**:
- **内部バッファリングの実装**
  - 書き込みを内部バッファに蓄積
  - 一定件数（例: 100件）ごとにバッチで永続化
  - Mutexロック回数: 1000回 → 10回（100倍削減）
  - SQLトランザクション数: 1000回 → 10回（100倍削減）

**期待される効果**:
- **300倍の高速化**（30秒 → 0.1秒）
- Beta版Python実装で実証済み

**根拠**:
- `others/BETA_ASYNC_PERFORMANCE_FIX.md` にて詳細に記録
- 実測データあり

### 2. 同期I/O処理 - WriteThrough モード（高優先）

**現状の問題点**:
- WriteThrough モードで各`set()`呼び出しごとにSQLite INSERTを実行
- スループット: わずか**29.79K ops/sec**
- Lazyモード（1.30M ops/sec）と比較して**43倍遅い**

**最適化の余地**:
- **バッチ書き込みの実装**
  - 内部バッファに蓄積し、一定件数でバッチINSERT
  - `BEGIN; INSERT...; INSERT...; COMMIT;` による効率化
  - ストレージへの書き込み回数を大幅削減

**期待される効果**:
- **43倍の高速化**（29.79K → 1.30M ops/sec）
- Lazyモード並みの性能を実現

**根拠**:
- `COMPREHENSIVE_BENCHMARK_RESULTS.md` のベンチマーク結果
- Lazyモードで既に1.30M ops/secを達成済み

### 3. 読み込みI/O処理（中優先）

**現状の問題点**:
- `batch_get()`でキャッシュミス時に個別にSQLクエリを実行
- N件のキャッシュミスで N回のSELECT文

**最適化の余地**:
- **キャッシュミスの一括処理**
  - キャッシュミスしたキーをまとめて1回のSQLで取得
  - `SELECT * FROM data WHERE key IN (?, ?, ...)`

**期待される効果**:
- **5-10倍の高速化**（キャッシュミス時）
- SQLクエリ回数: N回 → 1回

```rust
pub struct AsyncDictSQLite {
    cache: Arc<DashMap<String, Vec<u8>>>,
    storage: Arc<Mutex<Option<StorageEngine>>>,
    write_buffer: Arc<Mutex<HashMap<String, Vec<u8>>>>,  // 追加
    buffer_size: usize,  // 追加（例: 100）
    // ...
}

fn set_async(&self, key: String, value: Vec<u8>) -> PyResult<()> {
    self.cache.insert(key.clone(), value.clone());
    
    // バッファに追加
    let mut buffer = self.write_buffer.lock().unwrap();
    buffer.insert(key, value);
    
    // バッファがいっぱいになったらフラッシュ
    if buffer.len() >= self.buffer_size {
        drop(buffer);
        self.flush_buffer()?;
    }
    
    Ok(())
}
```

```rust
fn set(&self, key: String, value: Vec<u8>) -> PyResult<()> {
    self.hot_tier.insert(key.clone(), value.clone());
    
    if self.config.persist_mode == PersistMode::WriteThrough {
        let mut buffer = self.write_buffer.lock().unwrap();
        buffer.push((key, value));

}
```
