## バージョン文字列の構成

```
v{original}_v{fastest}_v{beta}
 │           │           │
 │           │           └─ dictsqlite_fastest_beta: 0.1.0-beta
 │           └─ dictsqlite_fastest: 1.0.0
 └─ dictsqlite: 1.8.9

例: v1.8.9_v1.0.0_v0.1.0-beta
```

## 主要な利点

### 1. 固定名での保存
- バージョンごとに同じ名前で保存
- 参照が容易
- スクリプトで自動処理可能

### 2. 上書き許可
- 同じバージョンの再実行で自動上書き
- 最新の結果のみ保持
- ストレージ効率的

### 3. 履歴管理
- すべての実行が記録される
- いつ、どのバージョンが実行されたか追跡可能

### 4. 詳細な比較
- 複数バージョン間の自動比較
- グラフで視覚化
- レポートで詳細分析

### 5. Git連携
- バージョン固有の結果はGit管理
- 一時ファイルは除外
- リポジトリサイズを最適化
