# DictSQLite v2.1.3 Release Notes

Release date: 2026-07-04

## Overview

DictSQLite v2.1.3 focuses on stability, performance, benchmark coverage, and release automation for the v2 Rust/PyO3 implementation.

## Highlights

- Hardened write-buffer flush behavior so failed flushes keep pending data available for retry.
- Fixed delete and clear behavior so buffered writes cannot resurrect removed keys.
- Fixed async table delete prefix handling and durable separate-table persistence.
- Added bulk read paths for batch cache misses and reduced warm-cache accounting overhead.
- Expanded benchmark coverage across sizes, quantities, modes, cold reads, mutation paths, and threaded access.
- Improved benchmark graph readability with compact labels and better aggregation.
- Added GitHub Actions benchmark artifacts, Markdown Summary output, and informational comparison history.
- Updated `anyhow` to `1.0.103` in the lockfile for RUSTSEC-2026-0190.

## Release Checklist

- Version bumped to `2.1.3` in Cargo and Python metadata.
- Changelog and PyPI README updated.
- Benchmark scripts and workflow YAML validated.
- Release build should be produced by the maintainer environment.
