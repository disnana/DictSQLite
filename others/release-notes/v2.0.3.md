# DictSQLite v2.0.3

**リリース日**: 2025年10月25日  
**タイプ**: パッチリリース（重要な修正）

## 🐛 重要な修正

### データベースロック問題の解決

v2.0.2以前のバージョンで発生していた深刻なデータベースロック問題を修正しました。

**問題の内容**:
- 並行操作時に `apsw.BusyError: database is locked` エラーが頻発
- バルク操作（bulk_insert, bulk_get）が使用不可能
- 高並行シナリオでの不安定性

**根本原因**:
1. 不適切なExecutor管理により複数スレッドが同一データベースにアクセス
2. EXCLUSIVEロックモードにより並行接続が阻害される
3. 自動フラッシュとバルク操作の競合

### 実装された解決策

**1. キューベースの操作シリアライゼーション**
```python
# 全てのデータベース操作をasyncio.Queueでシリアライズ
self._operation_queue = asyncio.Queue()
self._worker_task = asyncio.create_task(self._process_operations())
```

**2. 永続的なThreadPoolExecutor**
```python
# 単一スレッドの永続的Executorで同一スレッドローカル接続を使用
self._executor = ThreadPoolExecutor(max_workers=1)
```

**3. NORMALロックモード**
```python
# 複数接続の共存を許可
'locking_mode': 'NORMAL'  # EXCLUSIVEから変更
```

**4. 自動フラッシュの無効化**
```python
# 書き込みバッファの自動フラッシュを無効化、明示的なaflush()のみ許可
self._sync_db._write_buffer.flush_threshold = 1000000
```

## 📝 使用方法

```python
import asyncio
from dictsqlite import AsyncDictSQLite

async def example():
    async with AsyncDictSQLite('data.db') as db:
        # 並行操作が安定して動作
        tasks = [db.aset(f'key_{i}', f'value_{i}') for i in range(100)]
        await asyncio.gather(*tasks)
        
        # バルク操作も問題なく動作
        data = {f'bulk_{i}': f'value_{i}' for i in range(100)}
        await db.abulk_insert(data)

asyncio.run(example())
```
