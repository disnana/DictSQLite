# DictSQLite v1.8.0

**リリース日**: 2025年9月13日  
**タイプ**: メジャーリリース

## 🚀 主な特徴

DictSQLite v1.8.0は、SQLiteデータベースを辞書のように扱える革新的なPythonライブラリの初期安定版です。

### ✨ 新機能

- **辞書型インターフェース**: SQLiteを辞書のように直感的に操作
- **暗号化サポート**: データベースの暗号化機能を内蔵
- **トランザクション機能**: 安全なデータ操作のためのトランザクション
- **テーブル機能**: 複数のテーブルを簡単に管理
- **期限付き辞書**: ExpiringDict機能で一定時間後に自動削除
- **ファイルロック**: portalocker使用した安全なファイルアクセス

### 🔧 技術的改善

- **Pylint対応**: コード品質向上のためのpylint警告に対応
- **型ヒント**: 完全な型ヒントサポート
- **Python 3.9+**: Python 3.9以上をサポート

### 📝 ライセンス

- **MITライセンス**: カスタムMITライセンスを採用
- コードの自由な使用・改変が可能
- 元の作成者へのクレジット表示が必要

## 🔧 インストール

```bash
pip install dictsqlite
```

## 📖 基本的な使用方法

```python
from dictsqlite import DictSQLite

# データベースの初期化
db = DictSQLite('example.db')

# 基本操作
db['key'] = 'value'
print(db['key'])  # 'value'

# テーブルの使用
users = db.table('users')
users['user1'] = {'name': 'Alice', 'age': 30}

# 暗号化
encrypted_db = DictSQLite('secure.db', password='secret')
encrypted_db['secure_data'] = 'confidential'
```

## 🛠️ 依存関係

- `portalocker`: ファイルロック機能
- `cryptography`: 暗号化機能
