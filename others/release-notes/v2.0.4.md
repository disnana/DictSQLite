# DictSQLite v2.0.4

**リリース日**: 2025年11月1日  
**タイプ**: セキュリティパッチリリース（重要）

## 🔒 セキュリティ修正

### RUSTSEC-2025-0020の修正

**重要度**: 高

pyo3 0.20.3に存在したバッファオーバーフロー脆弱性を修正しました。

**問題の内容**:
- パッケージ: pyo3 0.20.3
- 脆弱性: バッファオーバーフロー
- 影響: メモリ破壊の可能性

**修正内容**:
- pyo3を0.20.3から0.24.1にアップグレード
- Bound API対応により、より安全なメモリ管理を実現

### コードセキュリティの改善

**機密データのログ出力防止**

テストコード内で機密情報が平文でログ出力される問題を修正:

```python
# 修正前
print(f"Password: {password}")
print(f"Salary: {salary}")

# 修正後
print("Password: [REDACTED]")
print("Salary: [REDACTED]")
```

**安全な一時ファイルの使用**

tempfile.mktemp()の使用を廃止し、安全なmkstemp()に変更:

```python
# 修正前（競合状態のリスク）
temp_file = tempfile.mktemp()

# 修正後（安全）
fd, temp_file = tempfile.mkstemp()
os.close(fd)
```

### API変更

**Rust API (内部実装のみ)**:

```rust
// v2.0.3
#[pymodule]
fn dictsqlite(_py: Python, m: &PyModule) -> PyResult<()> { }

// v2.0.4 (Bound API)
#[pymodule]
fn dictsqlite(m: &Bound<'_, PyModule>) -> PyResult<()> { }
```

**Python API**:
- 変更なし（完全互換）
