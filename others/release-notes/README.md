## 🔍 リリースタイプの説明

- **🏆 メジャー**: 大きな機能追加や破壊的変更
- **🔒 セキュリティ**: セキュリティに関する重要な修正
- **➕ マイナー**: 新機能の追加（後方互換性あり）
- **🔧 パッチ**: バグ修正や小さな改善
- **🧪 β版**: 実験的機能を含むベータリリース
