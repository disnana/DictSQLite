## 🔍 リリースタイプの説明

- **🏆 メジャー**: 大きな機能追加や破壊的変更
- **🔒 セキュリティ**: セキュリティに関する重要な修正
- **➕ マイナー**: 新機能の追加（後方互換性あり）
- **🔧 パッチ**: バグ修正や小さな改善
- **🧪 β版**: 実験的機能を含むベータリリース

## 📊 重要なマイルストーン

### 🚀 メジャーリリース

- **v2.0.0**: 🎉 **Rust実装による大幅な書き直し** - 5-300倍のパフォーマンス向上、True async/await サポート

### 🚨 緊急アップデート

- **v1.8.6**: Pickle脆弱性の修正（即座にアップデートを推奨）

### 🎯 主要機能追加

- **v2.0.0**: Rust実装、非同期処理、LRUキャッシュ、複数ストレージモード、テーブルサポート
- **v1.8.8**: JSON モードの実装（実験的）
- **v1.8.0**: DictSQLiteの初期公開
- **v1.8.3**: セキュリティ機能の強化
- **v1.8.5**: AI支援開発とテスト拡張
- **v1.7.3**: Pydantic統合とWALモード
- **v1.3.3**: プロジェクトの基礎確立

### 🔧 品質向上

- **v1.8.4**: 大規模なコード品質改善
- **v1.8.7**: 最終安定版としての完成
- **v1.3.7**: パフォーマンスと安定性の向上
