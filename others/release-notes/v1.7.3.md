# DictSQLite v1.7.3

**リリース日**: 2025年9月10日（推定）  
**タイプ**: マイナーリリース

## 🚀 新機能

### 🔗 Pydantic統合

- **Pydanticモデルサポート**: BaseModelを直接保存可能に
- **型安全性**: Pydanticによる厳密な型チェック
- **自動シリアライゼーション**: モデルの自動的な保存・読み込み

### 🗄️ データベースエンジン改善

- **WAL (Write-Ahead Logging) モード**: パフォーマンス向上のためのWALモード実装
- **Journal Mode設定**: カスタマイズ可能なジャーナルモード
- **Version 2プロトコル**: 次世代データベースフォーマットへの準備

### ⏰ ExpiringDict強化

- **期限付きデータ**: 自動期限切れ機能の改善
- **テーブル内期限切れ**: テーブル内でのexpiring_dict使用

## 📖 使用方法

### Pydanticモデルの使用

```python
from dictsqlite import DictSQLite
from pydantic import BaseModel

class Example(BaseModel):
    name: str
    age: int
    is_student: bool

# データベース初期化（v2プロトコル）
db = DictSQLite("example_v2.db", version=2, journal_mode="WAL")

# Pydanticモデルの保存
user = Example(name="Alice", age=30, is_student=False)
db["users"]["alice"] = user

# データの取得
print(db["users"]["alice"])  # Pydanticモデルとして復元
```

### WALモードの活用

```python
# WALモードでパフォーマンス向上
db = DictSQLite("fast.db", journal_mode="WAL")

# 大量データの効率的な処理
for i in range(1000):
    db[f"data_{i}"] = {"value": i, "processed": True}
```

### テーブル機能の強化

```python
# テーブル作成と管理
db.create_table("users")
db["users"]["key1"] = (1, 2, 3)
db["users"]["key2"] = {"nested": "data"}

# 期限付きデータの活用
db["users"]["temp_data"] = dictsqlite.expiring_dict(3)  # 3秒で期限切れ
db["users"]["temp_data"]["session"] = "temporary_session_data"
```

## 🔧 技術的改善

### データベースアーキテクチャ

- **Version 2プロトコル**: より効率的なデータ保存形式
- **WAL最適化**: 並行読み書きパフォーマンスの向上
- **メモリ効率**: より少ないメモリ使用量

### 型システム

- **Pydantic互換性**: 厳密な型チェックとバリデーション
- **自動変換**: Pythonオブジェクトとデータベース間の自動変換
- **スキーマ validation**: データ整合性の保証

## ⚠️ 重要な変更

### 新機能について

- **Version パラメータ**: `version=2` は次世代フォーマット
- **Journal Mode**: WALモード使用時の並行アクセス改善
- **Pydantic依存**: Pydanticモデル使用時は pydantic のインストールが必要

### 互換性

- **後方互換**: 既存のv1データベースはそのまま使用可能
- **段階的移行**: 必要に応じてv2フォーマットに移行可能
