# DictSQLite v1.8.6

**リリース日**: 2025年9月18日  
**タイプ**: セキュリティリリース（重要）

## 🚨 重要なセキュリティ修正

### 🔒 Pickle 任意コード実行脆弱性の対策

- **CVE対応**: Pickle deserialization の任意コード実行脆弱性を修正
- **安全な制限の追加**: pickle処理に厳格な制限を実装
- **SafePickle の導入**: 安全なpickle処理機能の実装

### 🛡️ セキュリティ強化

- **ホワイトリスト方式**: 許可されたクラスのみをデシリアライズ
- **サンドボックス実行**: 制限された環境でのpickle処理
- **実行前検証**: デシリアライズ前の安全性チェック

## 🔧 技術的詳細

### 🔐 Safe Pickle 実装

新しい `SafePolicy` クラスによる安全なpickle処理：

```python
from dictsqlite import DictSQLite, SafePolicy, safe_loads

# 安全なpickle設定
db = DictSQLite('secure.db', safe_pickle=True)

# カスタムセーフポリシー
policy = SafePolicy()
policy.allow_class('__builtin__', 'dict')
policy.allow_class('__builtin__', 'list')

# 安全なデータの読み込み
safe_data = safe_loads(pickle_data, policy)
```

### ⚠️ 制限の詳細

以下のクラス/モジュールは制限されます：

- **実行可能コード**: `exec`, `eval`, `compile`
- **ファイル操作**: `open`, `file`
- **システムコール**: `os.system`, `subprocess`
- **ネットワーク**: `socket`, `urllib`
- **任意のクラス**: 明示的に許可されていないクラス

## 🚀 新機能

### 🛠️ SafePickle API

```python
from dictsqlite.modules.safe_pickle import SafePolicy, safe_loads, safe_dumps

# セーフポリシーの作成
policy = SafePolicy()

# 基本データ型を許可
policy.allow_builtins(['dict', 'list', 'tuple', 'str', 'int', 'float'])

# 安全な保存と読み込み
safe_data = safe_dumps(data, policy)
loaded_data = safe_loads(safe_data, policy)
```

### 🔍 セキュリティログ

```python
# セキュリティイベントのロギング
db = DictSQLite('secure.db', security_logging=True)

# 不審な活動は自動的にログに記録
```

## ⚠️ 破壊的変更

### 🔄 移行が必要な場合

既存のデータベースで以下が使用されている場合：

1. **カスタムクラス**: 明示的な許可が必要
2. **複雑なオブジェクト**: SafePolicy での許可設定
3. **サードパーティオブジェクト**: ホワイトリスト登録

### 📋 移行手順

```python
# 1. 既存データのバックアップ
import shutil
shutil.copy('old.db', 'backup.db')

# 2. セーフポリシーの設定
from dictsqlite import DictSQLite, SafePolicy

policy = SafePolicy()
policy.allow_class('your_module', 'YourClass')

# 3. 安全な移行
db = DictSQLite('old.db', safe_pickle_policy=policy)
```
