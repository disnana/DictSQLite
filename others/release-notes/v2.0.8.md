# DictSQLite v2.0.8

**リリース日**: 2026年1月3日  
**タイプ**: パッチリリース

## 🎯 主要な改善：ARM版パッケージ配布対応

v2.0.8では、**ARM アーキテクチャ用のビルド済みパッケージの自動配布**を開始しました。これにより、Raspberry Pi、AWS Graviton、各種ARM環境でのインストールが簡単になりました。

### 対応アーキテクチャ

GitHub Actionsによる自動ビルド・配布により、以下のアーキテクチャに対応:

| プラットフォーム | アーキテクチャ | 対応状況 |
|----------------|--------------|--------|
| **Linux** | x86_64 | ✅ |
| **Linux** | ARM64 (aarch64) | ✅ **新規** |
| **Linux** | ARM32 (armv7l) | ✅ **新規** |
| **macOS** | x86_64 | ✅ |
| **macOS** | ARM64 (Apple Silicon) | ✅ |
| **Windows** | x86_64 | ✅ |
| **Windows** | ARM64 | ✅ **新規** |

### インストール

すべてのアーキテクチャで統一されたインストール方法:

```bash
pip install DictSQLite==2.0.8
```

pipが自動的に環境に合わせたパッケージを選択・インストールします。

**ARM環境での例（Raspberry Pi）**:
```bash
$ uname -m
aarch64

$ pip install DictSQLite==2.0.8
# ARM64用のビルド済みパッケージが自動インストール
```

## 🔧 CI/CD パイプライン

### GitHub Actions による自動配布

v2.0.8から、GitHub Actionsで複数アーキテクチャのビルドと自動配布を実装:

```yaml
# マルチアーキテクチャビルド対応
strategy:
  matrix:
    os: [ubuntu-latest, macos-latest, windows-latest]
    python-version: ['3.9', '3.10', '3.11', '3.12', '3.13']
    architecture: [x64, arm64]
```

**自動配布フロー**:
1. GitHub Releasesでタグ作成
2. 各アーキテクチャ向けにビルド
3. PyPIへ自動アップロード
