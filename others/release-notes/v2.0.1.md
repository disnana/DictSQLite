# DictSQLite v2.0.1

**リリース日**: 2025年10月15日  
**タイプ**: パッチリリース

## 🐛 バグ修正

### 非同期処理の安定性向上

- AsyncDictSQLiteの永続化機能を実装
- Memory/Lazy/WriteThroughモードに対応
- ストレージフォールバック機能を追加し、キャッシュミス時のデータアクセスを改善

### LRUキャッシュエビクション実装

- LRUキャッシュによる自動メモリ管理を実装
- アクセスパターンの追跡機能を追加
- 容量超過時の透過的なストレージ退避により、メモリリーク防止を実現

## 🔧 改善点

### ストレージ層の改善

- `flush()`および`close()`メソッドを追加し、データの永続化を確実に実行
- キャッシュミス時のフォールバック動作を最適化

### メモリ管理の強化

- LRUエビクションにより、大規模データセットでも安定動作
- メモリ使用量の無制限な増加を防止
