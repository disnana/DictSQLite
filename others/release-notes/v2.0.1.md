このリリースは安定性の向上を目的としたパッチリリースです。新機能の追加はありませんが、非同期処理を使用する場合は v2.0.0 から v2.0.1 へのアップグレードを推奨します。

## 📝 注意事項

- v2.0.0との完全な互換性を維持
- Python 3.9以上

## 📖 互換性

- バッチ読み込み: 5-10倍高速（v1.8.8比）
- 同期WriteThrough書き込み: 43倍高速（v1.8.8比）
- 非同期書き込み: 300倍高速（v1.8.8比）

v2.0.0のパフォーマンスを維持しつつ、安定性を向上:

## 📊 パフォーマンス

- メモリ使用量の無制限な増加を防止
- LRUエビクションにより、大規模データセットでも安定動作

### メモリ管理の強化

- キャッシュミス時のフォールバック動作を最適化
- `flush()`および`close()`メソッドを追加し、データの永続化を確実に実行

### ストレージ層の改善

## 🔧 改善点

- 容量超過時の透過的なストレージ退避により、メモリリーク防止を実現
- アクセスパターンの追跡機能を追加
- LRUキャッシュによる自動メモリ管理を実装

### LRUキャッシュエビクション実装

- ストレージフォールバック機能を追加し、キャッシュミス時のデータアクセスを改善
- Memory/Lazy/WriteThroughモードに対応
- AsyncDictSQLiteの永続化機能を実装
