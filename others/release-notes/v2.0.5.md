# DictSQLite v2.0.5

**リリース日**: 2025年11月15日  
**タイプ**: マイナーリリース

## 🔧 依存関係の更新

### Python バインディング

- pyo3を0.24.1から0.26へアップグレード
- より効率的なPython-Rust間のデータ変換を実現
- Python 3.13対応の準備

### 並行データ構造

- dashmapを5.5から6.0へアップグレード
- ロックフリーなHashMapのパフォーマンス改善

### 非同期ランタイム

- tokioを1.35から1.40へアップグレード
- 非同期処理の効率向上

## 📊 パフォーマンス

依存関係の更新により、以下のパフォーマンス向上を実現:

- Python-Rust間のデータ変換が約10%高速化
- 並行アクセス時のロック競合が減少
- 非同期処理のレイテンシが改善

## 🔧 改善点

### ビルドプロセスの最適化

- より新しいコンパイラ最適化を活用
- ビルド時間の短縮

### メモリ管理の改善

- pyo3の新しいメモリ管理機能を活用
- より効率的なリファレンスカウンティング

## 📖 互換性

- Python 3.9以上（Python 3.13も動作確認済み）
- v2.0.0～v2.0.4との完全な互換性を維持
- 既存のコードは変更不要

## 📝 技術的変更

### 主要な依存関係バージョン

| パッケージ | v2.0.4 | v2.0.5 |
|-----------|--------|--------|
| pyo3 | 0.24.1 | 0.26 |
| dashmap | 5.5 | 6.0 |
| tokio | 1.35 | 1.40 |

### API変更

Python APIには変更はありません。全てのコードが引き続き動作します。

## 🚀 使用方法

インストールまたはアップグレード:

```bash
pip install --upgrade dictsqlite
```

既存のコードはそのまま動作します:

```python
from dictsqlite import DictSQLite

db = DictSQLite('data.db')
db['key'] = 'value'
print(db['key'])  # 'value'
```
