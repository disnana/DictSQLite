# DictSQLite v1.8.8

**リリース日**: 2025年9月20日  
**タイプ**: マイナーリリース

## 🚀 新機能

### 📄 JSON モード（実験的）

- **JSON モードの実装**: 新しいJSONモードのテストバージョンを導入
- **Issue #16対応**: https://github.com/disnana/DictSQLite/issues/16 の実装
- **データ形式の拡張**: より柔軟なデータ保存形式のサポート

## 🔧 技術的改善

### 📝 ドキュメント更新

- **AI生成ドキュメント**: Gemini AIによる包括的なドキュメント更新
- **多言語対応**: 日本語と英語でのドキュメント改善
- **Issue #28対応**: https://github.com/disnana/DictSQLite/issues/28
- **注意**: AI生成のため、開発者による確認が推奨されます

### 🔧 型注釈修正

- **schema パラメータ**: main.py のコンストラクタ引数の型注釈を修正
  - **修正前**: `bool` (誤り)
  - **修正後**: `str | None` (正しい型)
- **ドキュメント整合性**: ドキュメント例との整合性を確保

### 🧹 コード品質

- **Pylint警告修正**: 複数のPylint警告に対応
- **コードスタイル**: より一貫したコーディングスタイル

## 📖 使用方法

### 基本的な使用（変更なし）

```python
from dictsqlite import DictSQLite

# 通常の使用
db = DictSQLite('example.db')
db['key'] = 'value'
```

### 新しいJSON モード（実験的）

```python
# JSON モードの使用（実験的）
db = DictSQLite('data.db', json_mode=True)
db['complex_data'] = {
    'nested': {
        'structure': ['array', 'data'],
        'timestamp': '2025-09-20'
    }
}
```

### スキーマ指定の正しい使用

```python
# 型注釈修正後の正しい使用
db = DictSQLite('schema_db.db', schema='custom_schema.sql')
# または
db = DictSQLite('auto_db.db', schema=None)  # デフォルト
```
