## 🚀 最終機能セット

### 💎 コア機能

```python
from dictsqlite import DictSQLite, expiring_dict, safe_pickle

# 基本的なデータベース操作
db = DictSQLite('final.db')
db['version'] = '1.8.7'

# テーブル機能
users = db.table('users')
users['alice'] = {'name': 'Alice', 'version': '1.8.7'}

# 暗号化サポート
encrypted_db = DictSQLite('secure.db', password='secret123')

# 期限付きデータ
expiring_cache = expiring_dict(3600)  # 1時間

# 安全なPickle処理
from dictsqlite.modules.safe_pickle import SafePolicy
policy = SafePolicy()
```
