# DictSQLite v1.8.3

**リリース日**: 2025年9月18日  
**タイプ**: マイナーリリース

## 🔒 セキュリティアップデート

### 🛡️ 実験的セキュリティ機能

- **試験的なセキュリティアップデート**: 新しいセキュリティ機能の導入（実験的）
- **脆弱性対策**: 潜在的なセキュリティリスクの軽減
- **データ保護強化**: より安全なデータ処理メカニズム

### 🔐 セキュリティ強化項目

- **入力検証の改善**: より厳密な入力値検証

## 📖 使用方法

### 基本的な使用（変更なし）

```python
from dictsqlite import DictSQLite

db = DictSQLite('secure.db')
db['data'] = 'secure_value'
```

### 新しいセキュリティ機能

```python
# セキュリティ強化モード（実験的）
db = DictSQLite('secure.db', security_mode='enhanced')
db['sensitive_data'] = 'classified'
```
