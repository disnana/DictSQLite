# DictSQLite v1.8.1

**リリース日**: 2025年9月15日  
**タイプ**: パッチリリース

## 🔧 改善と修正

### 📁 ファイル整理

- **プロジェクト構造の改善**: ファイルとディレクトリの整理を実施
- **コードベースの整理**: 不要なファイルの削除と構造の最適化
- **ドキュメントの整理**: ドキュメント構造の改善

### 🐛 バグ修正

- **例外処理の強化**: エラーハンドリングの範囲を拡大
- **Edge caseの対応**: より安全なエラー処理を実装
- **コードの安定性向上**: 実行時エラーの減少

### 🧹 コード品質

- **無駄な改行削除**: コードフォーマットの改善
- **コメントアウトの削除**: 不要なコメントアウトコードの除去
- **Pylint警告の対応**: 一部のPylint警告を無視設定

## 🚀 新機能

### 🛡️ セキュリティ強化

- **Copilot協力による改善**: GitHub Copilotと協力してコード品質を向上

## ⚠️ 重要な変更

- **Python バージョンサポート**: 対応バージョンの明確化
- **依存関係の更新**: より安定した依存関係の管理

## 📖 使用方法

従来の使用方法と変更なし：

```python
from dictsqlite import DictSQLite

# 基本的な使用は変更なし
db = DictSQLite('mydata.db')
db['key'] = 'value'
```
