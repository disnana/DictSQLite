```
├─ メトリクス記録

⏰ 長時間実行されるアプリケーション
├─ Webサーバー
├─ バックグラウンドワーカー
├─ デーモンプロセス
└─ 常駐アプリケーション

🚀 最高のパフォーマンスが必要
├─ 高負荷環境

```
