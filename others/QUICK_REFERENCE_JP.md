## ⚡ 1秒で決める

```
あなたのユースケースは？

┌─ 繰り返し同じデータを読み書きする ────────────→ Beta版 ✅

│
├─ 長時間実行される（サーバー、デーモン） ──────→ Beta版 ✅
```

## 📊 性能の違い（一目でわかる）

### Beta版が速い場面（圧勝）

| 操作 | 倍率 | 用途 |
|:-----|:-----|:-----|
| 書き込み（小～中量） | **3～11倍速い** | ログ、イベント記録 |
| キャッシュヒット後の読み込み | **8～12倍速い** | セッション、設定データ |
| バルク挿入（小～中量） | **1.05倍速い** | 一括データ投入 |

### Fastest版が速い場面（わずかに優位）

| 操作 | 倍率 | 用途 |
|:-----|:-----|:-----|
| 初回読み込み | **1.23倍速い** | 単発クエリ、バッチ処理 |
| バルク挿入（大量） | **1.03倍速い** | 大規模データ移行 |

## 🎯 典型的なユースケース

### Beta版を使うべき

```python
# ✅ Webアプリケーション（セッション管理）
db = DictSQLiteFastestBeta('sessions.db', memory_budget_mb=256)
session = db[user_id]  # 繰り返しアクセス → 8～12倍速い

# ✅ ログ収集システム
db = DictSQLiteFastestBeta('logs.db', memory_budget_mb=512)
for event in events:
    db[event.id] = event.data  # 書き込み多い → 3～11倍速い

# ✅ キャッシュサーバー
db = DictSQLiteFastestBeta('cache.db', memory_budget_mb=1024)
if key in db:
    return db[key]  # キャッシュヒット → 8～12倍速い
```

### Fastest版を使うべき

```python
# ✅ バッチ処理（一度だけ読み込み）
db = DictSQLiteFastest('data.db')
for key in all_keys:
    process(db[key])  # 初回のみ → Fastest版が23%速い

# ✅ データエクスポート
db = DictSQLiteFastest('export.db')
export_data = {k: db[k] for k in keys}  # 単発 → Fastest版が適切

# ✅ メモリ制約環境
db = DictSQLiteFastest('data.db')  # キャッシュなし → 最小メモリ
```

## 🎓 技術的な理解

### Beta版が初回読み込みで遅い理由

**処理時間の内訳（100回の読み込み）:**

```
ディスク読み込み:      80.5%  ← Fastest版と同じ
Beta版独自の処理:      19.5%  ← これがオーバーヘッド
  ├─ LRUキャッシュ操作:  8%
  ├─ アクセス頻度追跡:  4.6%
  ├─ バッファチェック:  3%
  ├─ 統計収集:          3%
  └─ その他:            1.9%
```

### その代わりに得られるもの

```
初回:     ▼ 23%遅い（キャッシュ構築コスト）
          ↓
2回目以降: ▲▲▲ 8～12倍速い（キャッシュヒット）
書き込み:  ▲▲▲ 3～11倍速い（バッファリング）
長期実行:  ▲▲▲▲▲ 総合5～10倍速い
```

## 🚀 パフォーマンスチューニングのヒント

### Beta版をさらに速くする

```python
# メモリ予算を増やす
db = DictSQLiteFastestBeta(
    'data.db',
    memory_budget_mb=1024  # デフォルトは100MB
)

# キャッシュサイズを手動設定
db = DictSQLiteFastestBeta(
    'data.db',
    cache_capacity=50000  # デフォルトは10000
)

# 書き込みバッファを大きくする
db = DictSQLiteFastestBeta(
    'data.db',
    write_buffer_size=5000  # デフォルトは1000
)
```

### Fastest版をシンプルに使う

```python
# デフォルト設定で十分
db = DictSQLiteFastest('data.db')

# 必要に応じてWALモードを有効化
db = DictSQLiteFastest(
    'data.db',
    journal_mode='WAL'
)
```
